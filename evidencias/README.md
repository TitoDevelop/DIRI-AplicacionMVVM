# Capturas para la entrega

El PDF (páginas 199-201) pide una captura de pantalla por cada requisito. Haz capturas reales, no imágenes inventadas, y guárdalas con estos nombres orientativos:

1. `01-menu-activo.png` — navegador con menú y página activa.
2. `02-listado-y-parametro.png` — catálogo; también captura `/juegos/vg03`.
3. `03-pagina-404.png` — URL inexistente.
4. `04-ayuda-preguntas.png` y `04-ayuda-referencia.png` — rutas anidadas.
5. `05-boton-ayuda.png` — acceso mediante botón Ayuda.
6. `06-ficha-seleccionada.png` — fila elegida y ficha con todos sus datos.
7. `07-busqueda-resultado.png` y `07-busqueda-sin-resultado.png` — búsqueda correcta y modal.
8. `08-filtro-opcional.png` — filtro por contenido, si decides entregar el extra.

Las capturas se realizan ejecutando la aplicación en tu navegador; aún no están hechas.
